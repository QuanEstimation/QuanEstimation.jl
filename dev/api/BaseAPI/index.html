QuanEstimationBase.QuanEstimationBase — Module
QuanEstimationBase

Core computational engine for quantum parameter estimation. Provides:

  • Dynamics: Lindblad, Hamiltonian, and Kraus evolution.
  • Objective functions: QFIM, CFIM, HCRB, NHB, and various Bayesian/von Neumann bounds.
  • Optimization: GRAPE, auto-GRAPE, AD, PSO, DE, DDPG, Nelder-Mead, and reverse-iterative algorithms for control, state, and measurement optimization.
  • Adaptive estimation: FOP, MI, and MZI-based adaptive schemes with online/offline modes.
  • Utilities: SU(N) generators, SIC-POVM, spin squeezing, error control, and evaluation tools.

QuanEstimationBase.AbstractKraus — Type

Kraus operator parameterization

This module provides the Kraus operator representation for quantum dynamics:

\[\rho = \sum_i K_i \rho_0 K_i^\dagger,\qquad \sum_i K_i^\dagger K_i = \mathbb{I}.\]

The Kraus operators $K_i$ completely characterize the quantum channel.

QuanEstimationBase.LLD — Method
LLD(ρ::Matrix{T}, dρ::Vector{Matrix{T}}; rep="original", eps=nothing, tol=1e-10,
    input_error=0.0, guard=nothing, diagnostics=false) where {T<:Complex}

Calculate the left logarithmic derivatives (LLDs). The LLD operator is defined as $\partial_{a}\rho=\mathcal{L}_a\rho$, where $\mathcal{L}_a = \mathcal{R}_a^\dagger$ and $\mathcal{R}_a$ is the RLD operator.

  • ρ: Density matrix.
  • dρ: Derivatives of the density matrix with respect to the unknown parameters to be estimated. For example, drho[1] is the derivative vector with respect to the first parameter.
  • rep: Representation of the LLD operator. Options are "original" (default) and "eigen".
  • eps: Deprecated relative spectral-floor factor. With the default nothing the relative precision policy is used; when supplied, eps is a relative floor, not machine epsilon.
  • tol, input_error, guard: Relative precision policy controls.
  • diagnostics: If true, also return one NumericalDiagnostics record per parameter.

Returns a vector of LLD matrices, or (Ls, diags) when diagnostics=true.

ChainRulesCore.rrule — Method
ChainRulesCore.rrule(::typeof(SLD), ρ::Matrix{T}, dρ::Matrix{T}; eps=nothing)

Custom reverse-mode automatic differentiation (AD) rule for the SLD operator.

This rule enables backpropagation through SLD(ρ, dρ) in AD frameworks (Zygote, etc.). The forward pass computes $L = \mathrm{SLD}(\rho, \partial\rho)$. The pullback maps the cotangent $\bar{L}$ to cotangents w.r.t. $\rho$ and $\partial\rho$.

Mathematical Definition

The pullback is the exact adjoint of the truncated (masked) forward map at the current mask. Let $G$ solve $(\rho G + G\rho)/2 = \bar{L}/2$ with the same spectral floor, $X = L + D$ the untruncated solution ($D$ the dropped blocks, kept in the forward diagnostics), $m$ the kept-channel mask, and hats denote the eigenbasis of $\rho$. Then

\[\bar{\rho} = -(G X + X G) + Q Z Q^\dagger,\qquad \bar{\partial\rho} = 2G,\]

where the projector-rotation term $Z$ accounts for the mask following the eigenbasis of $\rho$:

\[Z_{ki} = \frac{\bigl([\hat{L}, \hat{\bar{L}}] + [m\circ\hat{\bar{L}}, \hat{X}]\bigr)_{ki}} {\lambda_k - \lambda_i}\quad (k\neq i), \qquad Z_{kk}=0 .\]

The mask itself is locally constant; at a mask flip (a denominator crossing the spectral floor) or at a rank-change point the two-sided derivative does not exist and the pullback warns.

Arguments

  • ::typeof(SLD): The function signature for dispatch.
  • ρ::Matrix{T}: Density matrix.
  • dρ::Matrix{T}: Derivative of the density matrix.
  • eps::Float64=nothing: legacy relative spectral floor (deprecated).

Returns

  • Tuple{L, pullback}: The SLD $L$ and a pullback closure.

  • SLD: Forward SLD computation.

\[G_x = \sum_{j,k,l} \frac{\mathrm{Tr}\bigl[\sigma^{-1}(\partial_x\sigma)\sigma^{-1}A^{(l)}_{jk}\bigr]} {4\nu_j\nu_k + (-1)^l}\; \sigma^{-1}A^{(l)}_{jk}\sigma^{-1}.\]

QuanEstimationBase.Holevo_bound — Method
Holevo_bound(ρ::AbstractMatrix, dρ::AbstractVector, W::AbstractMatrix;
    eps=nothing, tol=1e-10, input_error=0.0, guard=nothing)

Compute the Holevo Cramér-Rao bound (HCRB) via semidefinite programming (SDP).

The HCRB is given by the optimization

\[\min_{V, X}\;\mathrm{Tr}(W V)\]

subject to the positive semi-definite constraint

\[\begin{pmatrix} V & X^\dagger R^\dagger \\ R X & \mathbb{I} \end{pmatrix} \succeq 0,\]

and the orthogonality conditions

\[X_i^\dagger \mathrm{vec}(\partial_j\rho) = \delta_{ij},\]

where $R$ is the LDLᵀ factor of the correlation matrix $S_{ab} = \mathrm{Tr}(\Lambda_a\Lambda_b\rho)$, and $\Lambda_a$ are the su(d) generators.

Arguments

  • ρ::AbstractMatrix: Density matrix.
  • dρ::AbstractVector: Vector of derivatives $\partial_a\rho$, one per parameter.
  • W::AbstractMatrix: Weight matrix (must satisfy $\mathrm{rank}(W)>1$ for non-trivial SDP; otherwise falls back to QFIM).
  • eps=nothing: Epsilon threshold for LDLᵀ rounding; legacy keyword; when nothing, the new relative precision policy is used; when given, it is deprecated and interpreted by the core.
  • tol=1e-10: Target relative accuracy.
  • input_error=0.0: Relative error of the input data.
  • guard=nothing: Relative spectral floor.

The LDLᵀ rounding tolerance is relative: the entries of the correlation matrix are rounded with a decimal precision derived from $\\max(\\mathrm{guard}, \\mathrm{input\\_error})\\,\\|S\\|_{\\max}$ (default guard = default_guard(Float64)), so the cutoff scales with the matrix magnitude instead of an absolute constant.

Returns

  • Float64: The HCRB value $\min\mathrm{Tr}(W V)$.

Note

For single-parameter or rank-1 weight matrices, this function falls back to the QFI/QFIM and does not invoke the SDP solver.

See Also

  • HCRB: Top-level dispatch (handles fallback logic).
  • decomposition: LDLᵀ factorization of $S$.
  • NHB: Nagaoka-Hayashi bound (alternative SDP bound).

QuanEstimationBase.Williamson_form — Method
Williamson_form(A::AbstractMatrix)

Perform the Williamson decomposition of a positive-definite $2N\times 2N$ covariance matrix $\sigma$.

Mathematical Definition

Any positive-definite real symmetric matrix $\sigma$ can be decomposed as

\[\sigma = S\,\mathrm{diag}(\nu_1,\dots,\nu_N,\nu_1,\dots,\nu_N)\,S^{\mathsf{T}},\]

where $S$ is a symplectic matrix and $\nu_k > 0$ are the symplectic eigenvalues. This function returns $S$ and the vector $(\nu_1,\dots,\nu_N)$.

The algorithm uses: $B = \sqrt{\sigma} J \sqrt{\sigma}$, Schur decomposition of $B$ to extract imaginary parts of eigenvalues, and constructs $S$ from the resulting diagonalising transformation.

Arguments

  • A::AbstractMatrix: The $2N\times 2N$ covariance matrix $\sigma$ (must be positive-definite).

Returns

  • S::Matrix: The symplectic matrix $S$.
  • c::Vector: The symplectic eigenvalues $(\nu_1,\dots,\nu_N)$.

  • ctrl: Control coefficients.

QuanEstimationBase.helstrom_bound — Function
helstrom_bound(ρ::AbstractMatrix{<:Number}, σ::AbstractMatrix{<:Number}, ν=1, P0=0.5)
helstrom_bound(ψ::AbstractVector{<:Number}, ϕ::AbstractVector{<:Number}, ν=1)

Compute the Helstrom bound for the minimum error probability in quantum hypothesis testing between two states.

Mathematical Definition

For density matrices $\rho$ and $\sigma$ with prior probabilities $P_0$ and $1-P_0$, the minimum error probability is lower-bounded by

\[P_{\mathrm{err}} \ge \frac{1}{2}\bigl(1 - \|P_0\rho - (1-P_0)\sigma\|_1\bigr).\]

For $\nu$ independent copies, the collective bound is

\[P_{\mathrm{err}}^{(\nu)} \ge \frac{1}{2}\bigl(1 - \|P_0\rho^{\otimes\nu} - (1-P_0)\sigma^{\otimes\nu}\|_1\bigr).\]

For pure states, this simplifies via the fidelity:

\[P_{\mathrm{err}}^{(\nu)} \ge \frac{1}{2}\bigl(1 - \sqrt{1-\mathcal{F}(|\psi\rangle,|\phi\rangle)^\nu}\bigr).\]

Arguments

  • ρ, σ: The two density matrices (or ψ, ϕ for pure states).
  • ν::Number=1: Number of independent copies.
  • P0::Float64=0.5: Prior probability for $\rho$.

Returns

  • Float64: The Helstrom bound on the error probability.

See Also

  • trace_norm: Trace norm used in the density-matrix formulation.
  • fidelity: Fidelity used in the pure-state formulation.
  • QZZB: Quantum Ziv-Zakai bound using the Helstrom bound.

For $d$ parameters with grids $x_1,\dots,x_d$, the mean estimate for parameter $i$ is

QuanEstimationBase.simpson — Method
simpson(x::AbstractVector, y::AbstractVector)

Numerical integration using the composite Simpson's rule.

For $n$ points with uniform spacing $h = (x_n-x_1)/(n-1)$:

\[\int_{x_1}^{x_n} f(x)\,\mathrm{d}x \approx \frac{h}{3}\Bigl(f_1+f_n + 4\sum_{\text{odd }i} f_i + 2\sum_{\text{even }i} f_i\Bigr).\]

If $n$ is even, a trapezoidal correction is applied to the last subinterval.

Arguments

  • x::AbstractVector: Abscissa points (must be uniformly spaced).
  • y::AbstractVector: Function values $f(x_i)$ at the abscissa points.

Returns

  • Float64: The approximate integral.

See Also

  • Trapz.trapz: Trapezoidal integration (used for multi-dimensional integrals).
